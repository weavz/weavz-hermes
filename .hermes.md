# Weavz MCP with Hermes Agent

When the configured Weavz MCP server is available, use it for tasks involving apps connected to the selected Weavz workspace. Discover current tool names and aliases first. Do not request pasted API keys, bearer tokens, OAuth tokens, or app passwords. Before external writes, state the exact target and proposed change and wait for approval.

MCP server state for this example belongs in `.local/hermes` via `HERMES_HOME`; do not change the default Hermes profile.
